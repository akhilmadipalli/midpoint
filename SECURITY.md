# Security Policy

Midpoint has Accessibility access, which lets it read and send mouse events, so security reports are taken seriously.

**Please don't open a public issue for security problems.** Report them privately through
[GitHub's private vulnerability reporting](https://github.com/akhilmadipalli/midpoint/security/advisories/new).
You'll get a response within a week.

Only the latest release is supported with fixes.
